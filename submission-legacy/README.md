# Stick Duel (legacy)

The submission files of the previous game, Stick Duel, kept for reference after the rework into
Topple Duel: the CrazyGames package (`crazygames/`), the GameDistribution package (`gd/`), the
GamePix package (`gamepix/`) and the old QA docs and screenshots (`docs/`). They are not built or
used any more.
